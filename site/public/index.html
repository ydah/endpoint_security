Before you connect

Apple’s Endpoint Security framework requires an approved, signed host executable.

  • ✓macOS 13+, CRuby 3.2+, and Xcode Command Line Tools
  • ✓An Apple-approved Endpoint Security client entitlement
  • ✓A signed host Ruby executable with Full Disk Access
  • ✓Root privileges when opening a client

The entitlement belongs to the host executable, not the gem. This project cannot grant or bypass Apple’s approval.
